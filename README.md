# \# Asteria

# 

# > A 2D Pixel Art MMORPG built around adventure, progression, exploration, and player freedom.

# 

# \*\*Asteria\*\* is a 2D top-down pixel art RPG evolving into an MMORPG experience. Players can create their own characters, choose and develop their classes, learn skills, complete quests, explore dungeons, gather resources, craft items, take on different jobs, and build a place they can call home.

# 

# The world of \*\*Asteria\*\* is designed around player progression and freedom, allowing players to develop their characters and experience the world in their own way.

#

# \## Features

# 

# \### Character Customization

# 

# Create and personalize your character with different customization options, allowing every player to have their own identity in the world of Asteria.

# 

# \### Class Tree

# 

# Develop your character through a branching class system. Choose your path and specialize your character based on your preferred playstyle.

# 

# \### Skill Tree

# 

# Unlock and develop abilities through a flexible skill progression system. Build your character around the skills and abilities you enjoy using.

# 

# \### Quests

# 

# Explore the world through quests, stories, objectives, and activities provided by the inhabitants of Asteria.

# 

# \### Dungeons

# 

# Challenge dangerous dungeons filled with enemies, encounters, rewards, and powerful challenges.

# 

# \### Crafting

# 

# Gather materials and use them to create equipment, items, and other useful resources.

# 

# \### Jobs

# 

# Take on different jobs and activities beyond traditional combat. Develop additional skills while contributing to the world around you.

# 

# \### Housing

# 

# Own and customize your own space. Build a home where you can store items, decorate, and create your personal place within Asteria.

# 

# \### NPCs

# 

# Interact with various NPCs throughout the world. Discover their stories, receive quests, trade items, and uncover more about Asteria.

# 

# \### And More

# 

# Asteria is an evolving project, with more gameplay systems, mechanics, locations, and content planned throughout development.

# 

# \## Vision

# 

# The goal of \*\*Asteria\*\* is to create a pixel-art MMORPG that offers players more than just combat.

# 

# The game aims to combine:

# 

# \*\*Adventure · Exploration · Progression · Crafting · Social Interaction · Customization · Player Freedom\*\*

# 

# Players should be able to decide how they want to experience the world — whether that means becoming a powerful adventurer, mastering crafting, pursuing different jobs, building a home, exploring dangerous dungeons, completing quests, or simply living their own life in Asteria.

#
